# 勞工權益計算機

🔗 **網站：[laogongquanyi.com](https://laogongquanyi.com)**

免費的勞動權益試算工具網站。依勞基法、勞工退休金條例、就業保險法、國軍退除役官兵輔導條例、公務人員請假規則等現行法規，讓使用者輸入幾個數字就能算出自己的權益。

## 資料流程：以資遣費試算為例

```mermaid
flowchart TD
    A["輸入到職日、離職日"] --> B["輸入各期間月薪<br/>（可新增多段）"]
    B --> C{"欄位都有填？<br/>日期合理？"}
    C -->|否| E["顯示錯誤提示"]
    C -->|是| D["展開成每月薪資表"]
    D --> F["取離職前 6 個月<br/>（未滿 6 個月取實際月份）"]
    F --> G["計算平均工資"]
    A --> H["計算年資<br/>年 / 月 / 日"]
    H --> I["基數 = 年資 × 0.5<br/>上限 6 個月"]
    G --> J["資遣費 = 平均工資 × 基數"]
    I --> J
    J --> K["顯示結果、年資、基數<br/>及後續補助資源連結"]
```

## 技術與做法

- **前端**：純 HTML、CSS、JavaScript，不依賴框架，載入快、維護簡單
- **版面**：CSS Grid 左右分欄（選單 1/3、內容 2/3），大分類可收合，手機版收成「☰ 選單」；暖色調設計並支援深色模式
- **部署**：GitHub Pages + 自訂網域（Porkbun DNS，強制 HTTPS）
- **SEO**：每頁獨立網址、`<title>` / `description`、canonical、`sitemap.xml`、FAQPage 結構化資料（JSON-LD）
- **分享預覽**：每頁有 Open Graph 標籤與專屬預覽圖（1200×630），分享到 LINE、Facebook 會顯示標題和圖片
- **數據**：GoatCounter 統計瀏覽量（不使用追蹤 Cookie）
- **隱私**：所有計算在使用者瀏覽器端完成，不傳送也不儲存任何輸入資料
- **年度數字集中管理**：勞健保級距、費率、稅率、俸點等每年要更新的數字都放在 `data.js`，頁面文字用 `<span data-v="...">` 自動帶入
- **分享**：每個試算結果下方有「複製結果」「分享給朋友」按鈕（`share.js`）

## 每年更新步驟

1. 打開 `data.js`，依各數字旁註解的來源查新年度公告，修改數字
2. 改 `YEAR`、`ROC`、`UPDATED`
3. 把所有頁面的 `data.js?v=` 版本號加 1，上傳
